ClipSaver — фоновое приложение для Windows, которое автоматически сохраняет весь копируемый текст в локальную базу данных с привязкой ко времени. Программа позволяет восстановить любой ранее скопированный фрагмент текста горячей клавишей. Распространяется в двух вариантах: исходный код на Python и готовый исполняемый EXE-файл.

ОСНОВНЫЕ ВОЗМОЖНОСТИ

Автоматический захват текста из буфера обмена каждые 3 секунды.

Сохранение последних 500 уникальных текстовых фрагментов.

Глобальная горячая клавиша Ctrl+Shift+V для вызова окна истории.

Фильтрация записей по тексту в реальном времени.

Восстановление любого сохранённого текста в буфер обмена двойным кликом.

Фоновая работа в системном трее.

Автоматический запуск вместе с Windows.

Ведение лога ошибок.

Низкое потребление оперативной памяти (10-15 МБ).

Минимальная нагрузка на процессор (менее 1%).

ВАРИАНТЫ УСТАНОВКИ

Вариант 1: Использование готового EXE-файла

Системные требования:

Windows 7, 8, 10 или 11 (x64).

Права на запись в папку %APPDATA%.

Права на создание ярлыка в папке автозагрузки.

Установка:

Скачайте файл ClipSaver.exe.

Поместите его в любую папку на вашем компьютере.

Запустите файл двойным кликом.

При первом запуске программа создаст папку %APPDATA%\ClipSaver и файл базы данных.

Программа автоматически добавит себя в автозагрузку.

В системном трее появится чёрная иконка с синим квадратом.

Вариант 2: Запуск из исходного кода

Системные требования:

Python версии 3.10 или выше.

Установленный pip.

Установка:

Скачайте файл ClipSaver.py.

Запустите файл командой: python ClipSaver.py

При первом запуске автоматически установятся все необходимые библиотеки.

Программа добавит себя в автозагрузку.

В системном трее появится чёрная иконка с синим квадратом.

Сборка EXE из исходного кода:
Для создания автономного исполняемого файла выполните команду:
pyinstaller --onefile --noconsole --add-data "icon.ico;." --icon icon.ico ClipSaver.py

ИСПОЛЬЗОВАНИЕ

Запуск:

После установки программа стартует автоматически при входе в систему.

Для ручного запуска дважды кликните по файлу ClipSaver.exe или выполните python ClipSaver.py.

Вызов истории:

Нажмите Ctrl+Shift+V в любом приложении.

Откроется окно с последними 50 записями.

Работа с историей:

В верхнем поле ввода введите ключевое слово для фильтрации записей.

Список обновляется автоматически при каждом введённом символе.

Двойной клик по любой записи копирует её содержимое обратно в буфер обмена.

Окно автоматически закрывается после выбора записи или при нажатии на крестик.

Управление через трей:

Кликните правой кнопкой мыши по иконке в системном трее.

Пункт Show History — открывает окно истории.

Пункт Exit — завершает работу программы.

ФАЙЛЫ И ХРАНИЛИЩЕ

Расположение данных (общее для обоих вариантов):
%APPDATA%\ClipSaver

Пример полного пути:
C:\Users\Имя_Пользователя\AppData\Roaming\ClipSaver

Структура папки:

history.db — база данных SQLite с сохранёнными текстами.

log.txt — журнал ошибок программы.

Ограничение хранилища:

База данных содержит не более 500 последних записей.

При превышении 500 записей старейшие автоматически удаляются.

При размере базы данных более 10 МБ выполняется автоматическая оптимизация.

Размер базы данных редко превышает 5 МБ.

УДАЛЕНИЕ

Для удаления программы:

Закройте программу через меню трея (Exit).

Удалите папку %APPDATA%\ClipSaver.

Удалите ярлык из папки автозагрузки (если создан вручную):
C:\Users\Имя_Пользователя\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup

Удалите файл ClipSaver.exe или ClipSaver.py.

УСТРАНЕНИЕ НЕИСПРАВНОСТЕЙ

Горячая клавиша не работает:

Убедитесь, что программа запущена (иконка в трее активна).

Проверьте, не занято ли сочетание Ctrl+Shift+V другим приложением.

Перезапустите программу через трей (Exit, затем запустите заново).

Текст не сохраняется:

Проверьте, что в буфере обмена находится обычный текст.

Программа сохраняет только текстовые данные. Изображения и файлы игнорируются.

Проверьте файл log.txt в папке %APPDATA%\ClipSaver.

Окно истории не открывается:

Убедитесь, что иконка в трее активна.

Попробуйте вызвать окно через меню трея (Show History).

Перезапустите программу.

Программа не запускается (EXE-версия):

Убедитесь, что файл не повреждён.

Проверьте права доступа к папке %APPDATA%.

Запустите файл от имени администратора.

Проверьте антивирус — он может блокировать программу. Добавьте файл в исключения.

Программа не запускается (версия с исходным кодом):

Установите Python версии 3.10 или выше.

Убедитесь, что все зависимости установлены.

Запустите командную строку от имени администратора и выполните:
python ClipSaver.py

Антивирус блокирует программу:

Добавьте файл ClipSaver.exe в исключения антивируса.

Программа использует стандартные системные вызовы и не содержит вредоносного кода.

ОГРАНИЧЕНИЯ

Сохраняется только текстовый контент. Изображения, файлы и другие бинарные данные игнорируются.

Максимальный объём истории — 500 записей.

Поиск работает только по сохранённому тексту.

Программа предназначена исключительно для операционной системы Windows x64.

Не поддерживает удалённое управление или синхронизацию между устройствами.

ТЕХНИЧЕСКИЕ ДЕТАЛИ

Используемые библиотеки (для версии с исходным кодом):

pyperclip — работа с буфером обмена.

keyboard — глобальные горячие клавиши.

pystray — иконка в системном трее.

winshell — создание ярлыка автозагрузки.

Pillow — создание иконки.

sqlite3 — локальное хранение данных (встроена в Python).

tkinter — графический интерфейс (встроен в Python).

Сборка EXE-файла:

Используется PyInstaller в режиме --onefile.

Все зависимости упакованы в один исполняемый файл.

Режим --noconsole обеспечивает работу без консольного окна.

Логирование:

Все ошибки записываются в log.txt.

Уровень логирования — ERROR (только критические ошибки).

Размер лога не ограничен, но редко превышает 1 МБ.

Потребление ресурсов:

Оперативная память: 10-15 МБ.

Процессор: менее 1% в фоновом режиме.

Дисковое пространство: зависит от объёма сохранённых текстов (обычно до 5 МБ для 500 записей).
