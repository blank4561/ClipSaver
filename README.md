# ClipSaver
ClipSaver — фоновое приложение для Windows, автоматически сохраняющее копируемый текст в базу данных. Восстановление через Ctrl+Shift+V. Распространяется как код (Python) и EXE. Возможности: захват текста каждые 3 сек, 500 записей, фильтрация, трей, автозагрузка, память 10-15 МБ. Установка EXE: запустите ClipSaver.exe. При первом запуске создаётся папка %APPDATA%\ClipSaver. Для кода: Python 3.10+, pip install pyperclip keyboard pystray winshell Pillow, затем python ClipSaver.py. Использование: Ctrl+Shift+V — окно истории. Двойной клик — копирование в буфер. Трей: Show History, Exit. Файлы: %APPDATA%\ClipSaver — history.db (500 записей), log.txt. Старые записи удаляются автоматически. Удаление: закройте через Exit, удалите папку %APPDATA%\ClipSaver и файл .exe/.py. Ограничения: только текст, 500 записей, Windows x64.
